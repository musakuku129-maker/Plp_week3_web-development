# Budget Tracker

This project is a polished budget tracker interface designed to improve the visual appeal and usability of an expense management page. The layout focuses on a clean and professional look, using a consistent color palette, modern typography, and structured cards for each major section.

## Files

- `index.html` – contains the page structure, including the heading, expense form, and expense table.
- `style.css` – applies the visual styling, including layout, colors, typography, buttons, table formatting, and spacing.

## What the page includes

- A prominent heading card with a soft gradient background.
- A styled form for adding new expenses with labeled inputs and buttons.
- A clear expense table with headers, alternating row colors, and status badges.
- Consistent spacing and card-based layout using the CSS box model.

## Design choices

- Color palette: blues, warm neutrals, and a soft accent orange for a modern financial dashboard look.
- Typography: headings use a serif display font, while body text and form controls use a clean sans-serif font.
- Layout: cards are separated by spacing, corners are rounded, and form/table sections are easy to scan.

## How to view the project

Open `index.html` in a browser to view the Budget Tracker design.
